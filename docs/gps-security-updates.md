# GPS security updates\n\n## University Wi-Fi middleware\n\nSet UNIVERSITY_WIFI_CIDR to the actual university IPv4 subnet, for example 10.42.0.0/16. Keep the real value in deployment configuration, not source control.\n\nProtect attendance routes with requireUniversityWifi(), for example: app.post('/api/attendance/check-in', requireUniversityWifi(), checkIn).\n\nIf Express is behind a load balancer or reverse proxy, configure app.set('trust proxy', ...) for known proxy addresses before relying on req.ip. Never blindly trust an arbitrary X-Forwarded-For header.\n\n## Mock-location detection\n\nThe React helper rejects malformed or obviously suspicious browser geolocation values. Browsers do not expose a standardized, security-grade API that proves a location was not spoofed, so this is a heuristic rather than definitive anti-spoofing.\n\nFor stronger assurance, combine server-side geofence checks with platform attestation/device-integrity APIs where supported, and treat browser coordinates as untrusted input.
