# GPS security updates\n\n## GPS location integrity\n\nThe React helper in `src/security/locationIntegrity.ts` validates browser geolocation before attendance is submitted.\n\nIt rejects malformed coordinates, impossible coordinate ranges, invalid accuracy values, extremely large accuracy values, and timestamps that are materially in the future.\n\nBrowsers do not expose a standardized, security-grade API that proves a location was not spoofed. These checks are therefore heuristics, not definitive anti-spoofing.\n\nThe backend must remain the authoritative security boundary: recalculate the attendance geofence distance server-side from the submitted coordinates and the classroom coordinates, and never trust a client-provided “inside geofence” flag.\n\nFor stronger anti-spoofing assurance, use platform/device attestation APIs where supported.
